- **범위**:
  - 포함: 한국은행 공개 API 연동, 일일 1회 갱신(오후 11시경), 네트워크 실패 시 이전값 유지

## 4. 외부 API
**한국은행 전시환율 공개 API**
- **URL**: `https://www.koreaexim.go.kr/site/program/financial/exchangeJson?authkey=`**`[authkey]`**`&searchdate=` **`[YYYYMMDD]`** `&data=AP01`
- **Source**: 한국은행 공식 (가장 신뢰도 높음)
- **Update**: 매일 오후 11시경 (1회)
- **응답**: 
  ```json
  [
    {
      "result": 1,
      "cur_unit": "USD",
      "ttb": "1473.50",
      "tts": "1475.50",
      "deal_bas_r": "1474.50",
      "bkpr": "1473.50",
      "yy_efee_r": "0.80",
      "ten_dd_efee_r": "0.80",
      "kftc_bkpr": "1473.50",
      "kftc_deal_bas_r": "1474.50",
      "cur_nm": "미국 달러"
    }
  ]
  ```
- **사용 필드**: `deal_bas_r` (거래중심환율) = **1474.50원**
- **authkey**: 무료 신청 (koreaexim.go.kr) 또는 공개 예제 키 사용 가능

## 5. 제약 조건
