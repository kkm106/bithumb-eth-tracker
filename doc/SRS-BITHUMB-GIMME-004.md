# SRS-BITHUMB-GIMME-004: 해외거래소 김프 실시간 표시

## 1. 개요
- **목적**: 국내 거래소(비트썸)와 해외 거래소의 이더리움 가격 차이를 실시간으로 계산하고 표시하여 사용자의 투자 판단 지원
- **범위**: 
  - 포함: Binance ETH/USDT 가격 조회, 비율 계산, 기존 대시보드 통합 표시
  - 제외: 외환(KRW/USD) 환율 자동 반영 (고정 환율 사용 또는 수동 설정)

## 2. 기능 요구사항 (FR)
| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| FR-001 | Binance 공개 API로 ETH/USDT 실시간 가격 조회 | **Must** |
| FR-002 | 비트썸 가격 대비 Binance 가격 차이를 % 기준으로 계산 (예: +1.5%, -0.8%) | **Must** |
| FR-003 | 비율 값을 색상으로 표시: 긍정(녹색), 부정(빨강색) | **Must** |
| FR-004 | 기존 통합 대시보드 ETH 정보 섹션에 김프 % 추가 표시 | **Must** |
| FR-005 | ETH 가격 조회 주기(10초)와 동일한 주기로 김프 데이터 갱신 | **Must** |

## 3. 비기능 요구사항 (NFR)
| ID | 분류 | 요구사항 |

## 4. 인터페이스 요구사항
- **API**: Binance Spot Trade API (무료, 인증 불필요)
  - 엔드포인트: `https://api.binance.com/api/v3/ticker/price?symbol=ETHUSDT`
  - 응답: `{ "symbol": "ETHUSDT", "price": "2345.67" }`
- **외부 연동**: 해외거래소 1개 (Binance) — 향후 확장 가능 (Not in Scope)

## 5. 제약 조건
- **기술 스택**: Node.js (기존 스택 유지)
- **환경**: 배포 환경 = 기존과 동일 (localhost:3000)
- **외환율**: 고정값 또는 수동 설정으로 사용 (자동 조회 X)
